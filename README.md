---

## 📌 Project Overview
KrishiSetu AI is an intelligent mobile and web app built to stop post-harvest food waste and make government market (Mandi) selling fast and easy for farmers across India.

### 🌟 Core Features:
1. **AI Camera Quality Grading:** Farmers take a photo of their crops. The app uses AI to check the quality instantly so they get a fair price. It works 100% offline!
2. **Predictive Mandi Slot Booking:** The system automatically checks how busy the markets are and gives the farmer a fixed time slot token. No more long lines!
3. **Smart Perishable Routing:** The app guides transport trucks using the fastest, traffic-free paths so fruits and vegetables do not spoil on the road.

---

## 🛠️ Tech Stack
* **Frontend:** React Native (For Mobile App) & React.js (For Web Dashboard)
* **Backend & AI:** Python (FastAPI) & TensorFlow Lite (For Offline Image Grading)
* **Database & Maps:** PostgreSQL & OpenStreetMap (For Route Tracking)

`[Photo Scan] ➔ [AI Quality Grading Offline] ➔ [Mandi Time Slot Assigned] ➔ [Driver Guided on Fastest Road] ➔ [Fair Sale]`
